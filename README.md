# Experimental-AMD-FP8-socket-footprint-KICAD-ONLY-
Hello! I am 40-96, and I am proud to announce that I have made an AMD FP8 socket for the open source community.

**A few disclaimers and warnings to address:**
- This footprint has a ball pitch with differences from 10-30 microns, so please double check the footprint and make any changes you'd like.
- While this is open-source, I cannot provide the pin out for any AMD Ryzen processors that are on the FP8 platform as that is intellectual, proprietary property that belongs to AMD.
- This uses an MIT license, meaning any boards made with this footprint are done with pure intention and full understanding that this is a beta and has not been tested or verified to work. I cannot be held responsible for any damages caused.
- All factory tolerances should be checked by the user, so any damages caused is yet again, not under my responsibility.
- Last but not least, enjoy and have fun in making your boards :3

Project outline:
- This socket was made solely by me and no external help was used from any industry experts. No artificial intelligence was used in the production of this footprint.

**Thank you so much yet again!**
